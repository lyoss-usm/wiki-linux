# Wiki Linux ![](https://img.shields.io/badge/estado-activo-green) ![](https://img.shields.io/github/license/lyoss-usm/wiki)

Este es el repositorio oficial de la Wiki Linux de Lyoss. Propuesta para crear una "Wiki" "moderna" e interactiva.

## Seguimiento
- Puedes seguir el progreso del proyecto en [GitHub Projects](https://github.com/lyoss-usm/wiki/projects).
- Para reportar problemas o sugerencias, visita [GitHub Issues](https://github.com/lyoss-usm/wiki/issues).

## Quick Start
1. Clona el repositorio:
    ```bash
    git clone https://github.com/lyoss-usm/wiki.git
    ```
2. Navega al directorio del proyecto:
    ```bash
    cd wiki-linux
    ```
3. Instala las dependencias:
    ```bash
    install dependencies
    ```
4. Ejecuta el proyecto:
    ```bash
    run project
    ```
